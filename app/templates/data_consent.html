DATA COVENANT

Discussion is not automatic model training.

A spiritual community must never hide a permanent training pipeline beneath vulnerable disclosure.

DEFAULT

No consent means no training copy.

Posts can still be displayed and analyzed for the community. The content is not copied into the model-training candidate table.

SEPARATE CONSENT

A checkbox is only the first gate.

Consent does not guarantee inclusion. Private content, crisis material, medical information, identifying details, unsupported claims, mixed claims, and contradictions are excluded.

THEOLOGICAL REVIEW

No content updates the model by itself.

Eligible material is marked pending_theological_review. A qualified human review process must approve the source, interpretation, privacy state, and intended training use.

REVOCATION

Deletion must reach derived datasets.

A production deployment must maintain lineage so a revoked or deleted contribution can be removed from candidate sets, exports, evaluation sets, and later model versions where technically possible.

The literal Bible-only model requirement

A hosted general-purpose language model has already been trained on broad human data. Strict retrieval can constrain what evidence it is allowed to use, but it cannot truthfully make those pretrained weights “Bible-only.” Literal compliance requires a separately trained or continued-pretrained model whose entire dataset is approved and provenance-tracked. This foundation does not pretend otherwise.
